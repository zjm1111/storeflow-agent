# StoreFlow｜AI 应用工程师面试问答卡（15 题）

使用方法：先遮住“回答要点”，用 15 秒给结论、45 秒说明项目实现和边界；再对照修正。不要逐字背诵。

## 1. 这是什么项目，解决什么痛点？

**回答要点**：区域采购负责人面对促销、天气、中央仓延迟和库存不足时，难以快速判断今天订多少。StoreFlow 汇集证据、识别风险、比较三种采购草案并交人工审核；不自动下单，首版范围为单门店/单 SKU/单周期。

## 2. 它是 Agent 还是 workflow？

**回答要点**：两者结合。研究层是受限 ReAct + Plan-Execute-Replan Agent：模型看 Observation 后选白名单工具。RRF、仿真、优化和 HITL 是确定性工作流，这样把高影响数值和权限锁在代码中。

## 3. ReAct 在项目中具体如何体现？

**回答要点**：每轮模型只返回 schema 校验后的 `{tool, reason}`；控制器执行只读工具，写入 observation；下一轮根据已有动作和覆盖缺口选择工具。最多 6 步、模型动作最多 2 次，不保存自由式思维链。

## 4. 为什么不直接用一个 RAG 问答？

**回答要点**：RAG 只能检索与生成摘要，不能自主发现库存/需求/配送/成本的哪一维缺证，也不能保证数值决策可复现。Agent 负责补证，算法层负责量化比较，HITL 负责高影响边界。

## 5. RRF 为什么必要？

**回答要点**：内部向量、BM25、记忆、公开风险的原始分数尺度不同，不能直接相加。RRF 用排名融合每条候选在不同通道的表现，再由 rerank 按当前问题精排。

## 6. 如何控制上下文和引用幻觉？

**回答要点**：先做质量、时效、scope 和多样性选择，token 预算内生成摘要；摘要始终绑定 Evidence ID，风险事件只能引用允许 ID，原文和 URL 保留回溯。网页/PDF/记忆都按不可信数据处理。

## 7. 长期记忆怎么避免污染？

**回答要点**：工作记忆只限当前任务，情景记忆只是案例快照；长期记忆仅由 reviewer 批准，保存证据、scope、审核人、有效期、置信度和替代关系。网页、模型草稿、失败任务不可直接写入。

## 8. 记忆与今天的证据冲突时怎么办？

**回答要点**：把它标为“历史记忆待复核”，不自动让旧经验覆盖近期天气、促销或配送证据；由审核人处理或产生新的替代记忆。

## 9. 为什么要人工审核？

**回答要点**：订货会影响缺货、损耗和现金占用，而输入可能过期或冲突。系统只产出建议草案；LangGraph interrupt 暂停，审核人能批准、改约束、补证或拒绝，且恢复有 MySQL checkpoint。

## 10. Monte Carlo 和 OR-Tools 分别做什么？

**回答要点**：Monte Carlo 在固定随机种子下模拟需求和到货延迟，计算成本、缺货概率、服务水平和 CVaR；OR-Tools 求满足预算、最大订货量和服务目标的高保障数量。两者共同避免让 LLM 直接做不稳定数值决策。

## 11. CVaR 是什么，为什么适合这里？

**回答要点**：CVaR 是最差一部分情景下的平均成本，项目使用最差 5%。平均成本相同的策略，尾部缺货/加急成本可能不同；CVaR 使高风险采购决策可比较。

## 12. 异步任务怎样做到可恢复？

**回答要点**：API 返回 202，Celery + Redis 异步执行；任务快照、版本和 checkpoint 持久化在 MySQL，worker 执行前核对版本；Redis Streams 保存事件，SSE 用 Last-Event-ID 续传。worker 丢失后可由新 worker 从持久化状态接续。

## 13. 你怎么处理外部模型或 Tavily 不可用？

**回答要点**：模型 JSON 异常、超时、429 或无 Key 会记录 trace/errors，并走确定性降级；Tavily 失败不阻断内部资料和记忆检索。控制台展示调用状态、token、成本费率状态和降级原因。

## 14. 如何评测它？哪些指标没有？

**回答要点**：仓库固化 48 个问题与 96 条 Evidence 标注，用于结构、引用、降级与回归；关键测试已通过。当前没有真实企业数据上的线上 Recall/NDCG、节省成本或 A/B 指标；需要历史回放和影子实验才能验证业务效果。

## 15. 当前最大技术短板与下一步？

**回答要点**：外部百炼/Tavily 路径验收约 92–116 秒，不能称生产级。下一步做缓存、并行 I/O、模型分级、历史回放、影子评测和多 SKU 扩展；保持人工审核和证据可追溯边界。
